
# RESQ

Location-Aware Disaster Evacuation and Rescue Coordination Platform

## Project Overview

RESQ is a decision-support prototype designed to identify
potentially affected registered users, coordinate rescue
cases, and recommend evacuation options using simulated
disaster scenarios.

## Technology Stack

- React + Vite
- Node.js + Express
- MongoDB + Mongoose
- Leaflet + OpenStreetMap
